# Hoge Next.js TypeScript Application

A simple Next.js application built with TypeScript that displays "hoge" in green text.

## About

This project was created on Replit, an online IDE that makes it easy to write and deploy code.

## Features

- Built with Next.js 
- Written in TypeScript
- Styled with JSX styles
- Displays "hoge" in green text

## Running the Application

To run this application:

```bash
npm run dev
```

The application will be available at http://localhost:5000

## Project Structure

- `pages/index.tsx` - The main page component that displays "hoge" in green text
- `next.config.js` - Next.js configuration
- `tsconfig.json` - TypeScript configuration

## Development

This project uses:
- Next.js for the frontend framework
- TypeScript for type safety
- JSX styles for component-level styling
